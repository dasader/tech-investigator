# 키워드 프롬프트 개선 + extraction_hint 분리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `INDICATOR_PROMPT`를 강화해 `search_keywords`를 OR 표현으로 넓히고, 별도 자연어 단서 필드 `extraction_hint`를 추가해 추출 정확도를 높인다.

**Architecture:** `indicators` 테이블에 `extraction_hint VARCHAR(500) NULL` 컬럼 추가. `indicator_agent`의 INDICATOR_PROMPT가 OR-style 키워드 + extraction_hint 둘 다 생성하도록 강화. `extraction_agent`는 hint가 있으면 indicators_json에 포함시키고 BATCH_EXTRACTION_PROMPT의 단서로 활용. 라우터·파이프라인은 dict 흐름에 hint 한 줄 추가하는 단순 wiring. 프론트엔드는 변경 없음 (사용자 미노출).

**Tech Stack:** SQLAlchemy + Alembic, Pydantic, FastAPI, pytest + unittest.mock, Gemini SDK (google.genai)

**스펙 참조:** `docs/superpowers/specs/2026-05-15-keyword-extraction-hint-design.md` (commit 5b77010)
